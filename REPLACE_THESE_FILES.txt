v58 photo-series architecture:
- Removes the runtime GitHub API directory request.
- Discovers numbered JPG files from the same site in the background as soon as the homepage loads.
- Preloads and decodes the cover plus nearby images before viewers navigate.
- Navigation uses request tokens so an older slow image can never overwrite a newer click.
- Fullscreen uses the same preloaded image cache and preloads adjacent images.
- Project page keeps the compact editorial viewer.
- Adds a 5-image COLLECTION PREVIEW below the viewer.
- VIEW ALL expands a magazine-style contact sheet of the whole discovered series.
- There is no LOADING label.

Important: truly instant loading still depends on image file size. If the original JPGs are very large,
the next best performance step is to add optimized preview WebP files while keeping the originals for fullscreen.
