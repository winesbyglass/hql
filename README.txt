REEL PERFORMANCE UPDATE

Replace your repository script.js with this script.js.
The Reel popup now opens with a preview and Play button. Vimeo loads only after Play.
For a guaranteed immediate preview image, upload a 16:9 JPG still from your reel to assets/reel-poster.jpg in your repository.
If you do not provide this JPG, the script tries to load the thumbnail from Vimeo.
No changes to your HTML or CSS are required.
If the browser caches the old script, change script.js?v=109 to script.js?v=110 (or a newer number) in index.html.
