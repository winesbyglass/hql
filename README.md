# Haohao Qiaoshi Liu — portfolio

This version uses the reference site's core layout logic: a fixed identity/navigation rail on the left and a dense image grid on the right. The palette is light and warm, with bold sans-serif typography rather than serif/editorial type.

## Preview locally

Double-click `index.html`, or open the folder with VS Code and use Live Server.

## Replace the temporary project art

Put your real film stills into `assets/` and update each `thumbnail` path in `projects.js`.

Example:

```js
thumbnail: "assets/distant-and-known.jpg"
```

For the best result, use landscape or square stills with at least 1600px width. The grid crops them to a square on desktop.

## Publish to the existing GitHub Pages site

Upload all files in this folder to the root of your existing `hql` repository and commit the changes. GitHub Pages will redeploy automatically.
